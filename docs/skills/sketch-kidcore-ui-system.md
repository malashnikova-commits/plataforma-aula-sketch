# Skill: Sketch Doodle Art · Minimalism Kidcore UI System

## Paleta estricta de 3 colores
- **Baby Powder (`#FEFEFA`)**: fondo de libreta, tarjetas, paneles, inputs y texto sobre acentos oscuros.
- **Gibraltar Sea (`#123850`)**: tipografía principal, bordes (`2.5px`–`3px`), sombras sólidas desplazadas (`6px` / `4px` / `3px`), iconos lineales y botones secundarios.
- **Gold Coast (`#D69A3F`)**: acento principal, botones CTA, barras de progreso, nodos activos, día "Hoy" y arcos del círculo unitario.
- **Tintes permitidos**: `#123850/70`, `#123850/30`, `#123850/10`, `#D69A3F/20`.

## Reglas de composición
1. Un solo foco principal por vista; formularios y ajustes avanzados siempre contraídos por defecto (`aria-expanded`).
2. Física táctil uniforme: `transition-transform duration-150 hover:-translate-y-0.5 active:translate-x-[2px] active:translate-y-[2px] active:shadow-none motion-reduce:transition-none`.
3. Sin textos de relleno, sin subtítulos redundantes ni métricas duplicadas.
